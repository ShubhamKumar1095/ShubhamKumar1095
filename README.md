# 💫 About Me

I'm Shubham, an **AI Engineer** based in Bengaluru, building agentic systems, LLM pipelines, and ML infrastructure tooling.<br>
I currently work at **Oracle** as an Associate Solutions & Integration Consultant, building automation scripts, PoCs, and integration pipelines for enterprise cloud platforms.<br>
Outside of work, I build **multi-agent architectures, RAG pipelines, and LLM-as-judge evaluation systems** — recent projects include a multi-agent trailer-generation pipeline and a six-layer LLM-as-judge pod-comparison tool (see below 👇).<br>
I'm actively exploring **AI/ML infrastructure, GenAI backend, and MLOps** roles, and I enjoy writing about what I learn along the way.
